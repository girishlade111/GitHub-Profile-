# GitHub-Profile-

A dark, cinematic single-page developer portfolio for **Girish Lade**, built as one self-contained `index.html` — no build step, no dependencies to install. Open it anywhere and it just works.

## ✨ Features

- **Hero section** — bold name/title intro with gradient accent branding
- **About** — short bio card highlighting the software-engineering transition
- **Skills grid** — grouped technology badges (languages, frameworks, tools)
- **Projects showcase** — cards for LadeStack products and experiments
- **Contact section** — direct links (email, GitHub, portfolio)
- **Cinematic styling** — dark theme with a subtle retro-tech background overlay, sparkle particle effects, and scroll-smooth navigation
- **Typography** — Inter from Google Fonts, Lucide icons via CDN

## 🛠️ Tech stack

Plain **HTML5 + CSS3 + JavaScript** · **Tailwind CSS** (CDN) · **Lucide** icons (CDN) · **Google Fonts** (Inter)

## 🚀 Getting started

No install, no build — it's a static page:

```bash
# Option 1: open directly
open index.html            # or double-click it

# Option 2: serve locally
npx serve .
# then visit http://localhost:3000
```

To customize: edit `index.html` — all markup, styles, and the sparkle-effect script live in that one file.
